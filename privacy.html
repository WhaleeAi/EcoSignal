Политика обработки персональных данных

Настоящая политика описывает, какие персональные данные EcoSignal получает при регистрации и использовании сервиса, зачем они нужны и как пользователь может обратиться по вопросам обработки данных.

Какие данные обрабатываются

При регистрации пользователь передает ФИО, email и пароль. Пароль хранится в виде хеша.

Цели обработки

Данные используются для создания учетной записи, авторизации, связи с пользователем, обработки экологических обращений и отображения информации о заявках в личном кабинете.

Правовое основание

Обработка выполняется на основании согласия пользователя, которое он дает при регистрации, отмечая чекбокс согласия на обработку персональных данных.

Передача данных

Данные могут быть доступны ответственным сотрудникам и организациям, которые обрабатывают обращения в рамках работы сервиса. Данные не используются для рекламной рассылки без отдельного согласия.

Отзыв согласия

Пользователь может запросить удаление учетной записи и связанных данных через администратора сервиса.
